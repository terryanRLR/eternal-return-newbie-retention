초보 관점 패치 기준 — 4구간

저픽률 · 고승률 — 접근성 개선 후보
성과는 좋지만 초보가 잘 선택하지 않음 → 추천 노출, 가이드, 입문 루트 보강
고픽률 · 고승률 — 신중한 관리 대상
초보 정착에 기여하는 입문 캐릭터일 수 있음 → 승률만 보고 급격한 너프 지양
저픽률 · 저승률 — 장기 개선 후보
현재 초보 유입 기여도가 낮음 → 구조, 조작 난이도, 재미 요소 점검
고픽률 · 저승률 — 이탈 위험 대상
많이 선택하지만 성과가 낮아 반복 패배로 이어질 수 있음 → 난이도 완화, 안내·성능 보정

이상치 ≠ 즉시 너프 — 캐릭터 진단

이상치 탐지(Isolation Forest)로 후보 선별 → SHAP로 승률 기여 구조 진단 → 패치 명단 ≠ 이상치
최종 제안
고승률 캐릭터는 즉시 너프보다 신중하게 검토하고, 고픽률·저승률 캐릭터는 초보 이탈 위험 대상으로 우선 점검한다. (이상치는 Isolation Forest·SHAP로 한 번 더 검증)
