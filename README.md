# 이터널리턴 초보 유저 이탈 진단과 정착 솔루션

카카오게임즈 배틀로얄 MOBA 게임 **이터널리턴**의 유저 플레이 로그(2024-05-30~06-12, 204,425건, 92,705명, 11,075매치)를 분석해 **초보 유저가 언제·어디서·왜 이탈하는지**를 진단하고, 임원진 / 기획자 / 밸런스팀 / 유저 4개 관점의 대시보드로 정착 개선 방향을 제안한 프로젝트입니다.

> **이 레포에 대해**: 원본 코드가 팀원별로 정리되지 않고 기획서·발표자료·중간 산출물·코드 일부만 남아 있었습니다. 이 레포는 남아있는 자료(기획서, Notion 인사이트 문서, 패치 검증 노트, 튜터 피드백, KPT 회고, 발표 PDF, 코드 조각, 완성된 대시보드 2종)를 교차 대조해서 **분석 파이프라인과 이슈/해결 과정을 역추적하고, 코드를 재구성·재분류**한 것입니다. 무엇이 실제 코드로 확인되는 것이고 무엇이 문서 근거로만 추정한 것인지는 각 문서에서 명시적으로 구분해 두었습니다.

## 핵심 결과 요약

- **이탈은 레벨 1~20에 집중**: 레벨 1~10 유저의 92.5%가 1판 후 미복귀 (11~20: 68.4%, 21~30: 56.1%). 재방문율은 레벨이 오를수록 단조 증가(7.5%→63.4%).
- **진짜 난이도 절벽은 11~40레벨**: 레벨 1~10이 지표상 가장 좋아 보이지만 이는 봇 매칭 보호 효과. 보호가 풀리는 11~40레벨에서 초반 사망률이 6.6%→12.9%로 급등.
- **사망의 87.2%가 플레이어 교전**: 초보는 파밍보다 '교전 패배'에서 무너짐  ⚠️ 이 수치의 산출 코드는 남아 있지 않습니다 — 인사이트 문서 서술 기준 ([`docs/02`](docs/02_analysis_pipeline.md) [4]절).
- **뉴비 정의**: `accountLevel≤60 AND rankPoint=0 AND matchingTeamMode=3(일반 스쿼드)` — 코발트 프로토콜(봇 포함 모드) 과대분류를 막기 위한 보정.
- **밸런스**: 승률×픽률 2변량 사분면의 한계를 인식하고 Isolation Forest(6지표) + SHAP으로 확장, "이상치 ≠ 즉시 너프" 원칙 하에 캐릭터별 개별 처방(너프 검토/신중 검토/출시효과 관찰 등)을 도출.
- **행동 군집**: K-means로 유저를 4개 군집(초반 이탈 위험군 / 일반 안정군 / 숙련 고성과군 / 포기·비정상 이탈군)으로 분류, 통계적 최적(k=2)보다 기획 활용도가 높은 k=4를 의도적으로 채택.

> **수치 출처 표기** — 위 항목 중 `92.5%` · `68.4%` · `56.1%` · `87.2%` 는
> 발표자료가 아니라 **팀 Notion 인사이트 문서**에 있던 수치입니다.
> 산출 코드가 남아 있지 않아 이번 재실행으로는 검증하지 못했습니다.
> 반면 `92,705명` · `204,425건` · `11,075매치` 는 발표자료와 원본 데이터 양쪽에서 확인됩니다.

자세한 인사이트와 액션 제안은 [`docs/03_issues_and_troubleshooting.md`](docs/03_issues_and_troubleshooting.md)와 [`slides/`](slides/)를 참고하세요.

- 원본 CSV가 레포에 없어 노트북은 **재현 가능한 형태로 정리**했을 뿐 실제로 재실행해 결과를 검증하지는 못했습니다.

- 그 외 모든 미해결/확인 필요 항목은 `docs/03_issues_and_troubleshooting.md` 하단 요약 표에 상태별로 정리되어 있습니다.
